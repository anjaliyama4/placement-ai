# AI Placement & Career Intelligence Platform

AI-powered placement and career management platform for students, recruiters, and administrators.

## Features
- Student dashboard
- Resume scoring
- Skill management
- Job search and matching
- Application tracking
- Interview preparation
- Recruiter portal
- Admin portal
- Career intelligence
- Notifications

## Technology Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- FastAPI
- Python
- PostgreSQL
- JWT Authentication
